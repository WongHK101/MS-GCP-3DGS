# M3M-GCP AutoDL 成本控制工作约定 v1

状态：`ACTIVE_WORKING_CONVENTION`  
生效时间：2026-08-27（Asia/Singapore）

本约定适用于后续 M3M-GCP / TGS-GCP 的 AutoDL 长时间训练、渲染和评测任务；除非用户在当前任务中明确要求保持开机，否则默认执行以下规则。

1. 最后一个已授权的服务器实验或评测进入终态后，先核验进程退出状态、最终模型、核心指标和轻量证据已落盘且可读。
2. 完成上述最小核验后立即普通关闭 AutoDL，不等待本机 Excel 整理、论文表格更新、审核会话回复或其他纯本机/CPU工作。
3. 方法以 OOM、算法错误或其他失败终止时同样适用；若没有已批准的后续服务器任务，不得为了等待人工查看而继续开机。
4. 只有两种情况允许保持开机：用户明确要求；或已有紧接着执行且仍需该服务器的已授权任务。
5. 监控任务负责执行关机，并在确认关机命令已发出后停止心跳；交付信息中明确记录关机时间、最后任务状态和保留模型位置。
6. 大模型默认留在服务器持久存储；关机前不为等待大模型回传而延长租用时间，除非用户明确要求先下载。

该约定是运行成本规则，不改变数据、算法、训练预算或评测协议。
