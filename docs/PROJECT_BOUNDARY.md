# Project Boundary

## Second paper

- Code, protocols, and public summaries live in this repository.
- Raw data, exact coordinates, model files, and run caches remain external.
- Server paths are supplied through launcher environment variables.

## First paper

The UMGS/TGRS repository, environment, datasets, and run roots are separate
and must not be modified by second-paper scripts.

DA3/VGGT-Omega experiments and the current TGRS depth-reference strategy
remain first-paper work unless a later explicit decision promotes a reusable
component into the second-paper repository.

Historical local provenance may retain machine paths outside Git. Public
reports must use project-relative identifiers or documented environment
variables.
